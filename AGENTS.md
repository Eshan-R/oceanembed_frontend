# OceanEmbed

This project is a static React SPA deployed via Netlify.
It uses TanStack Router (client-side) + TanStack Query + Vite + Tailwind CSS.

## Development Guidelines

- Do not introduce server-side rendering (SSR) or server functions.
- The build output is a plain static `dist/` folder — no Node.js server required.
- Keep the branch in a working state (builds clean with `npm run build`).
